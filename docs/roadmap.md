# Roadmap

- **Phase 0 — Foundation:** repo, license, monorepo scaffold, Docker Compose, CI. ← *we are here*
- **Phase 1 — MVP:** llm_gateway adapters, encrypted provider keys, agents CRUD + role templates, agent
  runtime with tools, inter-agent communication, live event timeline, cost tracking, 2D dashboard.
- **Phase 2 — 3D office:** React Three Fiber scene, desks and avatars animated by live events.
- **Phase 3 — Power features:** MCP client, code sandbox, human approvals, scheduled tasks, long-term
  memory, community role marketplace.
- **Phase 4 — Hosted cloud (paid):** multi-tenant, SSO, billing, included LLM credits.
