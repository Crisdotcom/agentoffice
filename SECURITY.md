# Security policy

AgentOffice stores LLM provider API keys and lets agents act on your behalf, so we take security reports
seriously.

**Please do not open public issues for vulnerabilities.** Use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository instead. We aim to acknowledge reports within 72 hours.

Supported versions: only the latest `main` while the project is pre-1.0.
